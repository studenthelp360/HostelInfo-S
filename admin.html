Google Sign-in Troubleshooting:

  1. Run on Server: Google OAuth blocks direct file:// paths. Run a local server (e.g. python -m http.server 8080) and load the page as http://localhost:8080/admin.html.
  2. Authorized Redirect URIs: In your Supabase Project console > Auth > Providers > Google, copy the redirect URL and bind it inside your Google Cloud Console Credentials page.
